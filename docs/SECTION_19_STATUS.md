## 4. What is genuinely unfinished, and what closes each item

1. **The app target has never been compiled** (highest risk; SwiftUI type errors are possible).
   → `xcodebuild -project ios/JarvisApp.xcodeproj -scheme JarvisApp -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO build`,
   or just push — the `ios` workflow runs it on a free `macos-14` runner.
2. **No `.ipa` exists yet.** → `./scripts/build_unsigned_ipa.sh` on a Mac, or download the workflow artifact.
3. **Live provider / OAuth / integration sends have never run.** → your key in the app's
   Settings ▸ AI Providers, and your Google/Meta projects per `docs/INTEGRATIONS.md`. No
   credential is required for anything else in this repository, and none is stored here.
4. **On-device behaviour is unverified** (orb, haptics, VoiceOver, Dynamic Type, notifications).
   → the 14-step checklist in `DEFINITION_OF_DONE.md` §3, ~10 minutes.
5. **CI is part-way there**: the repository is on GitHub and running, and the SwiftUI
   compile is the next thing the *Unsigned IPA* job will attempt now that the project
   file is readable. Two real defects were found by the first two runs and fixed.
